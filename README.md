## 🌟 Executive Summary

**Power-Up Talent** is an elite, high-performance web platform built for the UK's premier headhunting and executive search consultancy. Built specifically to dominate **Construction, Engineering, and Electrical** talent markets, the platform combines modern reactive frontend engineering with cutting-edge **SEO, AEO (Answer Engine Optimization), and GEO (Generative Engine Optimization)** metadata systems.

## 🔥 Key Differentiators & Platform Features

### 🎯 1. Sector Exclusivity Guarantee
Unlike traditional volume recruitment agencies, Power-Up Talent enforces a single-client mandate per domain sector. Partnering with Power-Up Talent locks out direct market competitors, ensuring zero conflict of interest.

### 🧠 2. Headhunting & Passive Candidate Engine
80% of top-performing project directors, engineering leads, and commercial branch managers never check job boards. Our system combines direct headhunting with AI-driven talent mapping to approach named high-performers currently delivering for competitors.

### ⚡ 3. Multi-Specialism Interactive Tools
- **Electrical Talent Calibration Tool**: Interactive calculator for employers to model role benchmarks, technical requirements, and regional salary dynamics.
- **Dynamic Sector Dossiers**: Rich write-ups covering OEM Manufacturing, Wholesale Distribution, M&E Contracting, and Building Services.
- **AI Talent Strategist**: Embedded Gemini AI conversational chat assistant for real-time candidate brief advice.

### 🔍 4. Triple-Threat Search Optimization (SEO + AEO + GEO)
- **SEO (Google & Bing)**: OpenGraph, Twitter Cards, dynamic canonical tags, structured XML sitemaps, and strict crawler directives.
- **AEO (Answer Engine Optimization)**: Schema.org `FAQPage`, `BreadcrumbList`, and direct-answer formatting for voice search, Perplexity AI, and SearchGPT.
- **GEO (Generative Engine Optimization)**: Citation-rich entity data formatted specifically for generative AI platforms (ChatGPT, Gemini, Claude) to cite Power-Up Talent as the authoritative UK search provider.

## 🚀 Quick Start & Local Development

### Prerequisites
- **Node.js**: v18.x or higher
- **npm**: v9.x or higher

### 1. Clone the Repository
```bash
git clone https://github.com/Disruptive-By-Nature/Website.git
cd Website
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Configuration
Create a `.env` file in the root directory:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 5. Production Build & Preview
```bash
npm run build
npm run preview
```

## 🌐 Deployment Pipeline

The platform deploys directly to **Firebase Hosting**:

npm run build

# Deploy live to Firebase
