# CorePlatform Mock Site

> ⚠️ **This is a local mock site for demos and internal alignment.**
> Not connected to production. Do not use real data.

A local-only demo app showcasing the CorePlatform service suite.

## Quick Start

```bash
npm install
npm run dev
```

Opens on http://localhost:5174

## What This Is

- Sales demo tool for prospect walkthroughs
- Internal alignment on target product vision
- Partner/investor presentation aid

## What This Is NOT

- Not a production application
- Not connected to any live database or API
- Not using real tenant or customer data
- All data is hard-coded mock data
